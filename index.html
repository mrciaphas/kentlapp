Torneo Mexicano de Robotica

En esta competencia fui parte del equipo de la UTCJ en el Torneo Mexicano de robótica, en la categoría de drones autónomos.

En este torneo competimos contra equipos de universidades de gran nivel, entre los que destacan la UNAM, el Tec de Monterrey y el Instituto Aeronáutico de Querétaro.

Después de 2 días de competencia en la UTBIS de Puebla, logramos un primer lugar contra equipos de mucha mayor categoría y nombre.

En este proyecto me encargué de diseñar sistemas de visión y movimientos autónomos para un dron DJI Tello, usando los sistemas de Tello y librerías de Python como NumPy y cv2.

Create Crew

Create Crew es un proyecto que pretendía conectar personas y crear equipos de trabajo para que pudieran, juntos, desarrollar proyectos que no podrían por sí mismos.

Aunque no se concretó ni hay planes de hacerlo en un futuro, funcionó como mi mayor proyecto y ejercicio, ya que el prototipo final era totalmente funcional, contando con una base de datos en Firebase y un diseño que permitía buscar perfiles compatibles con las necesidades de tu proyecto.

Sería el lugar en el que podrías encontrar un primer proyecto en calidad de colaborador en caso de que nunca hubieras llevado a cabo un proyecto grande.

AR Mural

Proyecto de desarrollo móvil creado con Magnet Ionic; es un programa que funciona para poder crear dibujos usando la cámara de un teléfono, y compartir la imagen con otro dispositivo en tiempo real para llevar a cabo murales.

El desarrollo de este proyecto se llevó a cabo con el combo clásico de desarrollo web, HTML, CSS, JS, compilado en Android Studio con npm para generar una aplicación de Android nativa.

Esta aplicación está actualmente en las fases finales de desarrollo y pronto se podrá descargar en Google Play.

Dronescript

De lejos la aplicación más compleja que he desarrollado; es una aplicación de programación por bloques que traduce los comandos programados en la pizarra a código en Python que controla drones del tipo DJI Tello.

Actualmente está en desarrollo, se usa el combo clásico de desarrollo web para la interfaz, el código enviado al dron es Python por medio de una API de Flask.

El objetivo de esta aplicación es liberar su código por completo, para que pueda, a través de plugins de diseño propio o de la comunidad, comunicarse con otros drones de código abierto como los Parrot Anafi u otros.
